# Antigravity Workspace Rule: Strict Minimalist Design & Taste Standards

Always adhere strictly to [DESIGN.md](file:///c:/Aafaque/Projects/B%20and%20B/DESIGN.md).

## Hard Rules (Zero Exceptions):
1. **NO "Pattiya" / Progress Bars**: Never add progress bars, free-delivery meters, percentage trackers, or colored horizontal line tracks. Use plain text inside bill breakdowns.
2. **NO Blinkers / Status Dots**: Never use pulsing dots (`animate-pulse`), colored indicator circles, or status dots. Plain text only.
3. **NO Pill / Badge Overuse**: Do not wrap text inside rounded pills/badges (`rounded-full bg-... border ...`). Rely on typographic hierarchy and whitespace.
4. **NO AI / Marketing Jargon**: Ban words like "Matrix", "Node", "Hub", "Zone 01", "Curated selection", "Optimized", "Gastronomic". Use honest everyday food language only ("Fresh Chicken Keema", "500g Portions", "Lunch Slot", "Dinner Slot").
5. **NO Neon Color Clashes**: Never slap neon WhatsApp green inside terracotta or dark buttons. Keep buttons cohesive and monochromatic.
6. **NO Dead-End Buttons**: Never block users with large disabled grey bricks. Always offer an active path forward.
